- **Author**: qing & Pi (Coordinator)
- **Source-Conversation**: 会话研讨实录（2026-10-31 灵感留存与系统边界定位架构推演）

## 1. 为什么做（Why）

### 1.1 核心痛点与认知冲突
在个人第二大脑与知识沉淀的日常实践中，存在一个极其典型的两难矛盾：
- **Ghost 的高神圣性与高信噪比门槛**：Ghost 定位于严肃数字双生，拥有严格的 OKF 元数据契约、动态概念向量池消解、MOC 看板、双向链接网及 11 项 Lint 静态校验。
- **日常碎片情报与即兴趣味的无处安放**：日常冲浪中高频偶遇大量“有趣却无用”的离散信息——一句喜欢的诗词文案、一个好玩的段子、一个今天看着很酷但暂未上生产的开源 GitHub 工具、一张极具幽默感的梗图。
- **现有方案的失效**：
  1. *若强行塞进 Ghost 炼化*：严重污染 Ghost 核心概念池与 MOC 拓扑，破坏严肃知识库的纯净度；且抓取一个梗图或段子还要写 frontmatter 跑流水线，心理阻力极大；
  2. *若单独新开日常 Agent 项目*：落入“高水平磨刀/生产性拖延”陷阱，徒增工程脚手架、鉴权与长链路维护成本。

### 1.2 动漫哲学与工程第一性双重回归
《攻壳机动队》中的 **Tachikoma（塔奇克马）** 拥有独立好奇心、自我吐槽机制、随时在数字前线搜集好玩战术情报的轻型多脚战车。
Tachikoma 的系统定位不应仅是冷冰冰的“输送管道”，更应是一个**战术侦察兵兼随身灵感军械库**：
1. **军需补给线（严肃进阶）**：负责多模态抓取直出 RFC-2026 规范，喂给 Ghost `_raw/` 进行不可变存盘与严肃炼化；
2. **战术军械库（灵感留痕）**：独立闭环承接离散、好玩、高趣味性的碎片情报，零门槛秒级摄入。

## 2. 改什么（What）

### 2.1 拒绝过度工程：坚决不搞 Ghost 重型炼化
- **不需要复杂概念消解**：碎片的核心价值在于“当下的原始语境与直觉”，强制拆解原子概念与向量融合会抹杀趣味；
- **不需要复杂的面向对象/领域本体建模**：扁平松散结构（TypeBox Schema + SQLite 单表 / JSONL）；
- **需要大模型极简提纯与多模态识图**：
  - 图/梗图：OCR 提字 + 视觉内核/风格识别；
  - 工具/链接：剥离营销词，提取“一句话本质 + 杀手级特性”；
  - 文案/段子：出处 + 触发点。

### 2.2 吸收核心心智：借鉴 Ghost「种子 ➔ 常青主干 (Seed-to-Evergreen)」自然演化
虽然不搞概念融合，但汲取 Ghost 的生命周期演化精髓，让碎片不会沦为“死垃圾堆”，而是具备有机成长能力：

```text
       [输入: 链接/文案/梗图/开源项目]
                       │
                       ▼ (tachikoma spark 秒级录入)
   ┌───────────────────────────────────────────────┐
   │ 阶段 1: 种子态 (Seed / Spark)                 │
   │ 零心智负担录入，大模型识图/提纯，打上基础标签   │
   └───────────────────────┬───────────────────────┘
                           │
                           ▼ (数量累积 / 标签自然聚类)
   ┌───────────────────────────────────────────────┐
   │ 阶段 2: 生长态 (Growing / Cluster)            │
   │ 碎片无序堆叠自然涌现主题簇（如 #CLI工具 堆叠出 │
   │ 「赛博装备库」，文案堆叠出「触动文案库」）     │
   └───────────────────────┬───────────────────────┘
                           │
                           ▼ (高频调用 或 严肃升级)
   ┌───────────────────────────────────────────────┐
   │ 阶段 3: 主干态 (Evergreen) / 升格 Ghost       │
   │ 成为高频随身兵器；或一键 tachikoma promote    │
   │ 打包直通 Ghost _raw/ 启动严肃 OKF 炼化         │
   └───────────────────────────────────────────────┘
```

### 2.3 落地拓扑与架构改动
在 Tachikoma Monorepo 中增加轻量支持：
1. **`packages/core`**：
   - 增加 `SparkRecord` 契约定义（`id`, `type`, `title`, `content`, `tags`, `raw_asset`, `status: seed|growing|evergreen`, `metadata`）；
   - 增加 SQLite `sparks` 表管理与 FTS5 全文检索引擎；
2. **`apps/cli`**：
   - 扩展 `tachikoma spark <content|url|image>` 命令（零心智秒级直存）；
   - 扩展 `tachikoma spark list / find` 命令；
   - 扩展 `tachikoma spark promote <id>`（升格推送至 Ghost `_raw/`）。

## 3. 原始对话研讨纪要与设计推演

```text
=== 原始研讨纪要整理（2026-10-31 跨架构设计） ===

用户痛点提出：
- Ghost 知识库很完整，但日常读文章或看图会有“有趣却无用”的信息（喜欢的诗句金句、好用的开源工具介绍、好玩的段子、梗图等）；
- 概率上不值得进入 Ghost 知识库留档或炼化；
- 提问：应该在 Ghost 开辟新内容，还是在 Tachikoma 中增强，还是单独开发面向日常的 Agent 项目？

AI 架构第一性诊断：
- 否定“开新 Agent 项目”：典型高水平磨刀/生产性拖延，带来维护负担与高录入摩擦；
- 否定“Ghost 混装/强行重型炼化”：污染严肃概念池与向量消解纯度，增加 frontmatter 与 lint 心智负担；
- 初步方案：Tachikoma 摄入端（轻量）+ Ghost 豁免专区（wiki/areas/sparks）。

用户深入洞察：
- “那听起来也可以在 Tachikoma 里闭环？”

架构认知跃迁：
- 在 Tachikoma 里闭环更加纯粹！
- 彻底契合《攻壳机动队》Tachikoma（塔奇克马）战术战车定位：具备独立好奇心与侦察兵属性，不只是单向输送带；
- 形成双轮驱动：
  1. 向 Ghost 输送严肃弹药（军需补给线）；
  2. 自身闭环留存感兴趣的离散战术情报（灵感军械库）。

用户追问与核心规约澄清：
- 问：是否不需要 LLM Wiki 炼化那一套？只是简单调用大模型识图或读内容打标签分类？
- 答：坚决不需要 Ghost 式概念消解与向量融合，但需要大模型轻量提纯（剥离营销水词、识图 OCR/风格提炼）；
- 问：借用 Ghost 的 SEA (Seed-Growing-Evergreen) 知识成长思想，方便自身自主拓充领域，但绝不用概念融合，仅做有机分类？
- 答：完全赞同！碎片以 Seed（种子）零摩擦入库，随着标签聚集自然涌现 Cluster（生长簇，如 CLI 装备库、文案库），高价值或被高频使用的成为 Evergreen（常青），真正需要严肃沉淀时支持一键 promote 升级至 Ghost。
```

## 4. 影响评估（Impact）

- **Ghost 影响**：**0 侵入**，Ghost 保持 100% 严肃高密度与现有 Lint/炼化流程不被污染；
- **Tachikoma 影响**：定位更加饱满，升级为多模态摄入与灵感军械库双核心引擎；
- **用户心智影响**：极度降低日常灵感记录门槛，告别心理负担。
